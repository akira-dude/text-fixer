# Localization

- `textfixer/i18n.py`: `t("key", **placeholders)`, `set_language(code)`, `languages()`.
  English (`en`) is the reference and the fallback for missing keys; unknown keys
  render as the key itself.
- `textfixer/locales/<code>.py`: one flat `STRINGS` dict per language.
  `locales/__init__.py` registers them in `LANGUAGES` with **explicit imports** —
  PyInstaller only bundles modules it sees imported, so no dynamic `importlib` here.
- The UI language is `Config.language` (`[ui] language` in `config.toml`), default `en`.
  The picker is in the settings window bottom bar. `App.apply_config` calls
  `set_language`; tray labels are callables, so `icon.update_menu()` re-renders them.
- Built-in styles follow the UI language while unedited (`builtin = true`, see
  `settings.md`); edited styles are user data and are never translated.
- The "How it works" tab (`settings.help.text`) is the user-facing explanation of the
  layout fix, answer language, Enter behavior, styles and privacy — keep it in sync
  with behavior changes. Paragraphs are split on blank lines; the first line of each
  paragraph renders as a heading. First start without an API key opens this tab.

## Rules

- Every user-visible string (tray, notifications, settings window, error messages that
  reach notifications) goes through `t()`. Log messages stay English and untranslated.
- Placeholders use `str.format` names; `t()` takes the key positionally, so any name
  (even `key`) is fine as a placeholder.
- Keys are grouped by prefix: `menu.*`, `tray.*`, `notify.*`, `test.*`, `llm.*`,
  `upd.*`, `hotkey.*`, `settings.*`.
- `tests/test_i18n.py` (also run in the release workflow) fails on: missing/extra keys
  in a locale, placeholder mismatch, a key used in code but not defined, a defined key
  that is never used. Keys built with f-strings are listed in its `DYNAMIC` map — update
  it when adding such keys.

## Adding a language

1. Copy `locales/en.py` to `locales/<code>.py`, translate values, keep placeholders.
2. Import it and add `"<code>": ("<native name>", <code>.STRINGS)` in `locales/__init__.py`.
3. Optionally add built-in styles for it in `config._DEFAULT_STYLES`.
4. `python -m tests.test_i18n`.
