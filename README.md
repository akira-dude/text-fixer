# TextFixer

Утилита в трее для Windows: исправляет текст в любом поле ввода (Discord, Telegram, браузер, Claude…) по горячей клавише.

- **Раскладка** (`ghbdtn` → `привет`, `руддщ` → `hello`) — локально, мгновенно, без интернета.
- **Орфография, заглавные, пунктуация** — через быструю удалённую модель (по умолчанию Groq, любой OpenAI-совместимый API).
- **Enter в Discord/Telegram**: если сообщение набрано не в той раскладке — сначала исправляется, потом отправляется.

## Установка

1. `setup.cmd` — создаст `.venv` и поставит зависимости.
2. `start.cmd` — запуск. При первом запуске откроется `config.toml`: впиши `api_key` (ключ с console.groq.com) и в трее нажми «Перечитать настройки».
3. Автозапуск — галочка в меню трея.

## Горячие клавиши (меняются в `config.toml`)

| Клавиши | Что делает |
| --- | --- |
| `Ctrl+Shift+Space` | раскладка + исправление через ИИ |
| `Ctrl+Shift+Enter` | то же и сразу отправить |
| `Pause` | только раскладка |
| `Enter` в приложениях из `auto_enter.apps` | исправить раскладку, если нужно, и отправить |

## Стили

Стиль исправления выбирается в трее (меню «Стиль»). Из коробки:

- **Мой стиль** — только орфография, запятые и заглавные; формулировки и сленг не трогаются, точка в конце не ставится.
- **Деловой** — переписывает сообщение в вежливом деловом тоне.

Тексты стилей и новые стили — в `config.toml`, разделы `[styles.<id>]`. Общие правила (не переводить, не отвечать на сообщение, сохранять ссылки и упоминания) зашиты в `textfixer/llm.py`.

Иконка: синяя — ждёт, жёлтая — ждём модель, красная — ошибка (подробности в уведомлении и `textfixer.log`). В логе только время и длина текста, сам текст не пишется.

## Как это работает

`Ctrl+A` → `Ctrl+C` → исправление → `Ctrl+A` → `Ctrl+V`, после чего старое содержимое буфера возвращается (только текст; картинка в буфере будет потеряна). Вставленный текст не попадает в историю `Win+V`.

## Ограничения

- Программы, запущенные от администратора, не принимают нажатия от обычного процесса — там TextFixer не сработает.
- Если в поле нет фокуса, `Ctrl+A` может выделить всю страницу; текст длиннее `max_chars` в ИИ не отправляется.
- Пока ждём модель, не печатай и не переключай окна (если окно сменилось — результат останется в буфере обмена).
